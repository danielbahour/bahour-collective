# BAHOURCOLLECTIVE


A responsive website I built for my independent DJ and creative work.

🌐 Live website: https://bahourcollective.com

## About the Project

Bahour Collective is a public-facing platform for showcasing DJ services, music, visual work, and event bookings.

I designed and developed the site from scratch with a focus on creating a clean, cinematic and responsive user experience.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Responsive desktop and mobile design
- Custom navigation and mobile menu
- Scroll-based animations
- Embedded music and social media content
- Interactive booking interface
- DJ services and portfolio sections
- Custom visual design and typography

## What I Worked On

I built the website structure, styling and interactive behaviour, including the responsive layout, navigation, animations and media integrations.
