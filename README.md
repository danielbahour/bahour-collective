# Bahour Collective

Website for my DJ project, Bahour Collective.

Live site: https://bahourcollective.com

I built the site myself using HTML, CSS and JavaScript. The goal was to make something clean, responsive and visually strong that could also handle bookings and showcase music/content.

## Built with

- HTML
- CSS
- JavaScript

## Main features

- Responsive design for desktop and mobile
- Mobile navigation
- Scroll animations
- Music and social media embeds
- Booking section
- Custom layout and styling

Most of the site is built in a single HTML file with the CSS and JavaScript included directly.
